ZebraSign

Sign a message as one of a group of GitHub users, using the SSH keys they already publish on GitHub. Anyone can check that one of them signed it, but not which one.

1Ring

GitHub usernames, one per line. Include your own. This page asks GitHub for each user's keys, so GitHub can see who you looked up. Each user uses 3 of the 60 requests GitHub allows per hour.

2Message
3Private key

The private key for one of your keys in the ring, such as the contents of ~/.ssh/id_ed25519. It stays in this page. A key you added to GitHub as a signing key is the better choice, since it can't push code.

4Signature

Everything runs in this page. Your private key and message aren't sent anywhere; the only network requests are to GitHub for public keys and avatars. Nothing is saved.

This is a test version. The RSA proof and the way different key types are combined haven't been reviewed by a cryptographer yet.
