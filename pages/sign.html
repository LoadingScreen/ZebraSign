Sign Verify

ZebraSignalpha

Sign a message as one of a group of GitHub users, using the SSH keys they already publish on GitHub. Anyone can check that one of them signed it, but not which one.

This is an alpha version, for testing with friends. The cryptography hasn't been reviewed yet and the signature format may change, so don't use it for anything that matters. Report problems on GitHub.

1Ring

GitHub usernames, one per line. Include your own. This page asks GitHub for each user's keys, so GitHub can see who you looked up. To hide that, open this page in Tor Browser or use a VPN. Each user uses 3 of the 60 requests GitHub allows per hour.

2Message
3Private key

The private key for one of your keys in the ring, such as the contents of ~/.ssh/zebrasign_test. It will stay in this page. A key you added to GitHub as a signing key is the better choice, since it can't push code.

How to copy it on other systems
  • Mac: in Terminal, run pbcopy < ~/.ssh/zebrasign_test
  • Windows: in PowerShell, run Get-Content $env:USERPROFILE\.ssh\zebrasign_test | Set-Clipboard
  • Linux: run cat ~/.ssh/zebrasign_test and copy everything it prints

For a key you already had, use its file name instead, such as id_ed25519 or id_rsa. It's the file without .pub at the end.

4Signature

Everything runs in this page. Your private key and message aren't sent anywhere. The only network requests are to GitHub for public keys and avatars. Nothing is saved.

The source code and a description of the cryptography are on GitHub.
