ZebraSignalpha

Check a ZebraSign signature. It shows which GitHub users the signer chose, and whether one of them signed the message, but it cannot show which one.

This is an alpha, for testing with friends. The cryptography hasn't been reviewed yet, so don't rely on a result here for anything that matters. Report problems on GitHub.

1Signature

The signature carries the public keys it was made with, so the check itself needs nothing from the network. This page then asks GitHub whether each key is still listed on its account. Nothing is saved.

The source code and a description of the cryptography are on GitHub.
